# healci-demo

A tiny Node.js project used to test HealCI end-to-end.

- `add.js` — a trivial function.
- `add.test.js` — a passing unit test (`node --test`).
- `.github/workflows/ci.yml` — CI generated by HealCI's workflow builder
  (SHA-pinned actions, least-privilege permissions, Node matrix, cache).

This is the **happy path**: CI should be green. A follow-up will introduce a
bug so HealCI can detect the failure and propose a fix.
